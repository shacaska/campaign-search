      How it works

      Campaign pages make it hard to find something mentioned in update #37 of 120. This site keeps a plain-text copy of every update so you can search them all at once.

      Indexing (for everyone)

      When you paste a campaign that isn't indexed yet, the site opens a pre-filled GitHub issue. A GitHub Actions job then downloads the campaign's updates and saves them in this repository, where everyone can search them. Indexed campaigns are refreshed daily, so new updates show up automatically.

      Servers can only see public updates. Backer-only updates show their title but not their text.

      Bookmarklet (for backer-only updates, or instant search)

      The bookmarklet runs on the campaign page in your browser, so it can read backer-only updates you have access to. Nothing is sent anywhere. It opens a search panel right on the page.
