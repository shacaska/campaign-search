Search every update of a Kickstarter or Gamefound campaign

Looking for the one update that mentioned the eidolons? Add the search button once, open a campaign, tap it, and type. It reads all the updates and highlights every mention.

  1. Add the search button (once)

    Drag this button onto your bookmarks bar. If the bar is hidden, press Ctrl/⌘ + Shift + B.

    🔎 Search updates

    Prefer a button that's always there? Install the userscript with Tampermonkey or Violentmonkey. It adds a “Search updates” button to every campaign page.

    2. In Chrome, bookmark this page (⋮ → ☆), then open ⋮ → Bookmarks, and edit the new bookmark.
    3. Name it searchupdates and replace the URL with the code you copied. Save.
    4. To use it: on a campaign page, tap the address bar, type searchupdates, and tap the suggestion with the ☆ star (not the 🔍 search one).

    ⚠️ Android Chrome won't run it if you tap it in the Bookmarks list. It only works from the address bar, as in step 4.

    2. In Safari, tap Share → Add Bookmark → Save.
    3. Open Bookmarks (📖), tap Edit, tap the new bookmark, rename it Search updates, and replace the address with the code you copied. Done.
    4. To use it: on a campaign page, open Bookmarks and tap Search updates.

    With the free Userscripts Safari extension you can install the userscript instead, which adds a permanent button.

  2. Open a campaign

    This opens the campaign's Updates page. On Android it always opens in Chrome, even if you have the Kickstarter or Gamefound app. Or just go there the way you normally would.

  3. Tap the button and search

    A search panel slides in. The first time, it reads every update. That takes a few seconds on Kickstarter, and about a second per update on Gamefound. After that it opens instantly and only fetches new updates.

    Tips: "phoebe eidolon" for an exact phrase · -stl to exclude a word · matching ignores case and accents, and eidolon also finds eidolons.

FAQ

Does it see backer-only updates?

Yes, if you're logged in as a backer. It runs in your own browser with your own login, exactly as if you opened each update yourself. Updates you can't see show up as 🔒 with their title only.

Is anything sent anywhere?

No. Everything happens on the campaign's own site, in your browser. The update text is cached in your browser so the next search is instant. There's no server and no tracking.

Why can't I just paste a link here and search?

Kickstarter and Gamefound block automated downloads from servers with “verify you are human” checks. The button works because it runs as you, on a page you've already opened.

Can I keep a copy or search offline?

In the search panel, tap Save .json. You can open that file here later and search it.

The button does nothing, or says it can't load

On Android Chrome, start it from the address bar. It won't run from the Bookmarks list. If you get a “could not load” message, use the standalone version instead: it's longer, but it doesn't need to download anything.

Something broke

The sites change their pages sometimes. Please open an issue with the campaign link and the error message shown in the panel.
